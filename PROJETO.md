# ESMERATECH Editor de Cartaz: informações do projeto

## Endereços

- Repositório: https://github.com/esmeraldorg-alt/esmeratech-cartaz
- Site publicado (GitHub Pages): https://esmeraldorg-alt.github.io/esmeratech-cartaz/
- Branch com as novidades: `modelos-editor-busca` (ainda não foi para o `main`, que é o site publicado)

## Funcionalidades

- Lista de produtos com nome e preço (ex.: `6,50 KG`).
- Modelos de cartaz, tamanhos A1 a A7 e títulos. Folhas A4 para colar.
- Modelo de imagem: escolha uma imagem ou cole o link dela.
- Buscar imagem com licença livre no Wikimedia Commons (só CC0, domínio público, CC BY e CC BY-SA; NC e ND ficam de fora).
- Editar modelo (cópia de um padrão ou modelo próprio), excluir modelo próprio, baixar e importar modelo em .json. Modelos ficam salvos no aparelho.
- Baixar PNG e imprimir.

## Versão do cache

`esmeratech-cartaz-v3` (em `sw.js`). Troque o número sempre que mudar os arquivos publicados, para o celular atualizar o app.
